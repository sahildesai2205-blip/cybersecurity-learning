# Module 2: Network Components, Types, and Connections

## 1. Client and Server
A client requests a service or resource, and a server responds. For example, a web browser requests a webpage from a web server. Mail servers provide email services, and file servers provide file storage and sharing.

## 2. Peer-to-Peer (P2P) Networks
In a peer-to-peer network, devices can act as both clients and servers. They can share resources directly without requiring a dedicated central server for every task.

### Advantages
- Often easy to set up
- Can be cost-effective
- Relatively simple for small networks
- Useful for sharing files and printers

### Disadvantages
- Security and access control can be harder to manage
- No central administration by default
- May be difficult to scale as the network grows
- Devices sharing resources may experience performance impacts

## 3. Multiple Roles in a Network
A device can perform multiple roles. For example, a computer can request files as a client while also sharing files as a server. A device's role depends on the service or communication taking place.

## 4. Network Infrastructure
Network infrastructure includes end devices, intermediary devices and network media.

### End Devices
Devices that send or receive data, such as laptops, desktops, tablets, IP phones and printers. These are also commonly called hosts when participating in network communication.

### Intermediary Devices
- **Switch:** Connects devices within a local area network (LAN).
- **Router:** Connects different networks and forwards traffic between them.
- **Wireless access point:** Allows wireless devices to connect to a network.
- **Firewall:** Filters network traffic according to configured security rules.

### Network Media
The means through which data travels, including copper cables, fiber-optic cables and wireless signals.

## 5. LAN and WAN
- **LAN (Local Area Network):** Connects devices within a limited area, such as a home, office or building.
- **WAN (Wide Area Network):** Connects networks across larger geographic areas.

LAN and WAN describe network scope, not physical transmission media.

## 6. Internet Service Providers (ISPs)
An Internet Service Provider supplies Internet connectivity to homes and organizations, connecting their networks to the wider Internet.

### Common Connectivity Options
- **Cable:** Internet access delivered over cable infrastructure, often shared with television services.
- **DSL (Digital Subscriber Line):** Internet access over telephone lines. Depending on the technology, voice and data can operate simultaneously.
- **Cellular:** Uses a mobile network and cell towers to provide connectivity.
- **Satellite:** Uses satellite communication to provide connectivity, including in some remote areas.
- **Dial-up:** Uses a telephone connection and is generally much slower than modern broadband options.

## Key Takeaways
- Clients request services; servers provide them.
- P2P devices can act as both clients and servers.
- Switches connect devices in a LAN; routers forward traffic between networks.
- Network media carry data.
- ISPs provide connectivity between customer networks and the Internet.
